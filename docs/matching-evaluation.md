# 상품 매칭 개선과 성능 비교

무신사 상품과 KREAM 상품이 같은 상품인지 정하는 단계의 문제, 시도한 방법, 측정 결과를 정리했다. 수치는 모두 `docs/evaluation/matching_eval.json`(고정 데이터)에서 다시 계산할 수 있다.

```powershell
.\.venv\Scripts\python.exe -m shop_comparator.matching.evaluate
```

## 1. 문제

기존 데스크톱 프로그램의 매칭 규칙은 두 줄이었다.

1. 무신사 품번으로 KREAM을 검색해, 검색 결과 중 **품번이 같은 상품**을 고른다.
2. 없으면 **검색 결과의 첫 번째 상품**을 고른다.

이 규칙은 두 가지 이유로 틀린 매칭을 만들었다.

| 원인 | 실제 예 |
|---|---|
| 같은 상품인데 두 쇼핑몰의 품번이 다르다. 무신사 품번이 판매자의 자체 관리번호인 브랜드가 많다. | 무신사 품번 `NBPDGF733B_19`, KREAM 모델번호 `U740BM2`. 실제 모델번호는 무신사 상품명 "NBPDGF733B / **U740BM2** (BLACK)" 안에 있다. |
| 표기만 다르다. | 무신사 `VN000D3HBKA1`, KREAM `VN000D3HBKA` |
| 품번이 같아도 다른 상품이다. | 에어포스 1 화이트 `CW2288-111`은 일반판과 트래비스 스캇 협업판이 같은 모델번호를 쓴다. 기존 프로그램이 저장해 둔 매칭은 협업판이었다. |
| 품번이 안 맞으면 첫 번째 결과를 그대로 쓴다. | KREAM에 없는 국내 브랜드 구두를 검색하면 비슷한 이름의 다른 브랜드 상품이 첫 번째로 나온다. |

틀린 매칭은 곧 틀린 가격 비교다. 다른 상품의 시세와 비교한 "차익"은 의미가 없다.

## 2. 시도한 방법

| 단계 | 방법 | 비용 | 구현 |
|---|---|---|---|
| A | **모델번호 대조 확장**. KREAM 상품 페이지의 모델번호를 읽고, 무신사 품번뿐 아니라 상품명 속 모델번호도 대조한다. 기호를 빼고 비교하며 3자 이내 접미 차이는 허용한다. **일치하는 후보가 정확히 하나일 때만** 확정한다. | 0원 | `shop_comparator/matching/match_review.py` |
| B | **이미지 판정(VLM)**. A로 확정하지 못한 상품은 무신사 썸네일과 KREAM 후보 썸네일을 비전 모델에 보내 `same / different / uncertain`, 고른 후보, 신뢰도, 사유를 정해진 JSON 형식으로 받는다. | 모델별 | `shop_comparator/matching/vlm_match.py` |
| C | **사람 확인**. VLM의 "동일"은 자동 등록하지 않는다. 이미지를 나란히 넣은 엑셀로 확인한 뒤 등록한다. | | `match_review.py export` |

B 단계에서 비교한 모델

| 모델 | 실행 위치 | 사용 범위 |
|---|---|---|
| `gpt-5.4-nano` | OpenAI API | 10개 표본 (비용·정확도 측정) |
| `gpt-5.4-mini` | OpenAI API | 246개 전체 |
| `Qwen3-VL-8B` | 자체 GPU PC (RTX 4090, LM Studio) | 이미지 쌍 100개 벤치마크 (5절) |

세 모델을 같은 이미지 쌍으로 비교한 결과는 5절에 있다.

## 3. 평가 방법

- **대상**: 무신사 신발 랭킹에서 수집한 상품 중 KREAM 검색 후보가 있는 246개(2026-10-09 수집). 후보는 상품당 1~10개.
- **기존 규칙 재현**: 저장된 검색 결과에 기존 규칙을 그대로 적용했다(`evaluate.legacy_pick`). 기존 프로그램은 검색 카드에 모델번호가 없어 품번 비교가 더 자주 실패했으므로, 이 재현은 기존 규칙에 유리한 쪽이다.
- **정답**
  - 모델번호가 일치하는 후보가 하나뿐이면 그 후보를 정답으로 본다(제조사가 붙인 식별자). 153개.
  - 그 밖의 상품은 사람이 확인한 라벨만 정답으로 쓴다(`docs/evaluation/review_labels.csv`, 24개). 무신사 이미지와 후보 이미지를 나란히 놓고 상품명·모델번호와 함께 판정했다. 썸네일로 가릴 수 없는 3개는 "판단 보류"로 두고 맞음·틀림 어느 쪽에도 넣지 않았다.
  - 라벨이 없는 상품은 "확인하지 않음"으로 따로 센다. 추정으로 채우지 않았다.

| 항목 | 결과 |

VLM이 새로 찾은 14개의 성격

- 품번이 판매자 자체 코드라 모델번호 대조가 불가능했던 상품: 리복 클럽 C 85(`RXSOXXCVUBK` ↔ `AR0454/100000153`), 블런드스톤 585, 레드윙 포스트맨 101, 팀버랜드 넬리(`23399-713` ↔ `TB1233997131`) 등
- KREAM에 모델번호가 없는 국내 브랜드: 포스트맨, 르무통, 액트플러스, 네거티브쓰리
- 같은 모델번호를 여러 상품이 써서 자동 확정을 보류했던 상품: 에어포스 1 화이트(일반판과 협업판 중 일반판을 고름), 락피쉬 부츠(색상별 상품 중 맞는 색상을 고름)

VLM이 틀린 6개의 성격

- 브랜드가 다른 비슷한 구두 2개 (신뢰도 0.96, 0.88)
- 같은 브랜드의 다른 모델 3개 (팀버랜드 18094 ↔ 10061 계열 등)
- 색상과 소재가 다른 상품 1개 (클락스 왈라비 GTX)

"동일" 판정의 정밀도는 확인된 20개 기준 70%다. 신뢰도 0.9 이상에서도 오판이 있었다. 그래서 **VLM의 "동일"은 후보 제안으로만 쓰고 사람이 확인한 뒤 등록한다.**

### 5.4 해석

- **쉬운 쌍은 세 모델 모두 잘 가른다.** 모델번호가 다른 상품(`other_model`) 44개에서 42~43개를 맞혔다.
- **차이는 "얼마나 과감하게 동일이라고 답하는가"에서 난다.** Qwen은 거의 다 찾지만 틀린 "동일"이 5건이고, nano는 틀린 "동일"이 없지만 절반을 놓친다. mini가 그 사이다.
- **어려운 쌍은 모두 어렵다.** 사람이 틀렸다고 확인한 6쌍(`reviewed_not`)에서 Qwen은 4건을 다시 "동일"이라고 했고(신뢰도 0.95~0.98), mini는 4건을 "불확실"로 넘겼다. 같은 브랜드의 비슷한 모델(팀버랜드 18094 ↔ 10061 계열)이나 다른 브랜드의 닮은 구두다.
- **신뢰도 값으로는 자동화할 수 없다.** Qwen은 맞은 판정과 틀린 판정의 신뢰도가 같은 범위다.
- 그래서 실제 파이프라인은 모델번호 대조를 먼저 하고, VLM은 후보 제안에만 쓰고, 등록은 사람이 확인한 뒤에 한다. 비용만 보면 로컬 모델로 넓게 찾고 mini로 다시 거르는 2단 구성이 합리적이지만, 이 조합은 아직 측정하지 않았다.

### 5.5 조건과 한계

- Qwen은 서버가 정한 프롬프트로 두 이미지를 비교하는 API(`/compare`)만 제공한다. OpenAI 모델에는 이 프로젝트의 프롬프트를 썼다. **프롬프트가 같지 않다.**
- Qwen의 응답 값 중 "같은 모델의 다른 변형"(9건)은 가격 비교 기준에서 다른 상품이므로 "다름"으로 셌다. 그중 2건은 사람이 "동일"로 라벨한 쌍(킨 재스퍼, 르무통 메이트)이어서 틀린 것으로 셌는데, 라벨 쪽이 틀렸을 가능성도 있다.
- 100쌍, 신발 한 범주, 512px 썸네일 한 장씩이다. 1~2건 차이는 의미 있는 차이가 아니다.
- 원격 서버의 접속 정보와 클라이언트는 저장소에 없다. `VLM_REMOTE_COMMAND` 환경 변수로 실행 파일 경로만 넘긴다. 벤치마크는 한 번에 한 건씩 호출하고 2회 연속 실패하면 멈춘다.
- Ollama용 백엔드(`vlm_match --local`)도 구현했지만 실제 모델로 실행하지는 않았다.

## 6. 결론

| 질문 | 답 |
|---|---|
| 품번이 달라 못 찾던 문제가 해결됐는가 | 부분적으로 해결됐다. 찾은 상품이 118개에서 167개로 늘었다. 남은 79개는 KREAM에 같은 상품이 없거나 확인하지 못한 상품이다. |
| 틀린 매칭은 줄었는가 | 줄었다. 기존 규칙은 128개에 첫 번째 결과를 썼고 확인분의 85%가 틀렸다. 현재는 확정하지 못하면 매칭하지 않는다. |
| VLM만으로 충분한가 | 아니다. 모델번호가 맞는 상품은 97% 맞히지만, 모델번호가 없는 상품에서 "동일"의 30%가 틀렸다. 세 모델 벤치마크에서도 틀린 "동일"이 없는 모델은 절반을 놓쳤다. 모델번호 → VLM → 사람 순서가 필요하다. |
| 어떤 VLM이 나은가 | 용도에 따라 다르다. 찾는 능력은 로컬 Qwen3-VL-8B(재현율 94%), 틀린 매칭을 피하는 능력은 gpt-5.4-nano(오판 0), 균형은 gpt-5.4-mini다. |
| 비용은 | 모델번호 대조는 0원. `gpt-5.4-mini`로 확정하지 못한 상품만 보내면 100개당 약 100원 수준이다. |

## 7. 한계

- 정답 라벨은 작성자가 이미지·상품명·모델번호로 판정한 것이다. 독립된 검수자의 교차 확인은 하지 않았다.
- 모델번호 일치를 정답으로 간주했다. KREAM이 같은 상품을 두 번 등록한 경우(하루타 HS-906)는 한쪽만 정답으로 센다.
- VLM이 "다름"이라고 한 66개는 전부 확인하지 않았다. 놓친 동일 상품(재현율)은 측정하지 못했다.
- 신발 랭킹 한 범주, 한 시점의 데이터다. 의류나 다른 시점에는 다를 수 있다.
- 썸네일(512px) 한 장씩만 비교한다. 색상만 다른 상품은 썸네일로 구분하기 어렵다.
