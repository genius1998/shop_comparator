# 검증 상태 구분

기능마다 어디까지 확인했는지를 같은 여섯 단계로 적는다. 위 단계가 아래 단계를 뜻하지 않는다.

| 단계 | 뜻 |
|---|---|
| 구현 완료 | 코드가 있다 |
| 모의 테스트만 확인 | `tests/`의 자동 테스트(임시 DB, 가짜 응답)로만 확인 |
| 로컬 통합 확인 | 로컬 Flask 서버와 실제 SQLite 파일로 끝까지 실행. 외부 응답은 저장 결과 재생일 수 있다 |
| 실제 운영 확인 | 실제 쇼핑몰이나 실제 모델을 상대로 실행 |
| 실제 사람 검수 완료 | 사람이 화면에서 직접 판단한 기록이 있다 |
| 미실행 | 실행하지 않았다 |

## 아직 입증되지 않은 주장

| 주장 | 상태 |
|---|---|
| "VLM이 사람의 검토 시간을 줄인다" | 측정 없음. 측정 환경과 절차만 있다 |
| "매칭 정확도가 N%다" | 사람이 만든 정답이 없다. 118 → 153 → 167은 확보한 매칭 수다 |
| "VLM 제안이 N% 맞는다" | AI 보조 검토 기준의 수치만 있다. 사람 정답 기준 수치는 없다 |
| "규칙(`local`)이 확정한 매칭은 맞다" | 측정 없음. 정답 검수 대상에 넣었다 |
| "오매칭이 없다" | 어떤 방법에도 근거가 없다 |
| "완전 자동으로 운영된다" | 구현하지 않았다. 사람의 승인이 필요하다 |
| "가격 차이만큼 수익이 난다" | 수수료·배송비를 반영하지 않았다 |
