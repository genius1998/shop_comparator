## 2. 무신사

### 2.1 재고·사이즈 (로그인 없음)

상품 1527076 (아식스 조그 100 T W (2E) - 블랙 / 1022A335-001)

| 사이즈 | 225 | 230 | 235 | 240 | 245 | 250 | 255 |
|---|---|---|---|---|---|---|---|
| 재고 | 품절 | 품절 | 있음 | 있음 | 있음 | 있음 | 품절 |

7개 사이즈 중 구매 가능 4개. 이전 작업의 관측과 같다. 신발 랭킹 상위 3개(7466121, 5619910, 3276429) 목록 조회와 수집도 성공했다.

### 2.2 회원가

로그인 계정 등급: 브론즈. 사이즈마다 장바구니 → 주문서 → 쿠폰을 각각 조회했다.

| 상품 | 사이즈 수 | 판매가 | 최대 할인 쿠폰 | 등급 할인 | 적립금 선할인 | 회원가 |
|---|---|---|---|---|---|---|
| 7466121 NBRJGF010F / WINTER Breeze | 5 (220~260) | 169,000 | 6,760 (10월 무신사 회원 정기 쿠폰 브론즈 등급) | 1,620 | 1,600 | 159,020 |
| 3976349 에어 포스 1 07 M - 블랙 | 12 (245~300) | 149,000 | 5,960 (같은 쿠폰) | 1,430 | 1,550 | 140,060 |
| 3976350 에어 포스 1 07 M - 화이트 | 12 (250~305) | 수집 성공 | | | | |

계산 확인(3976349): 149,000 − 5,960 = 143,040. 등급 할인 1,430 = 내림10(143,040 × 1%). 143,040 − 1,430 − 1,550 = 140,060. 저장된 값과 같다.

세 상품 모두 옵션별 판매가가 같아 사이즈별 회원가가 같게 나왔다. 값은 사이즈마다 따로 조회한 결과다(로그에 사이즈별 조회 기록).

### 2.3 주문 불가 상품

1527076은 장바구니 담기는 성공(HTTP 200, SUCCESS)하지만 주문서 API가 `FAIL / ORDER-111-0005 / 판매가 종료된 상품이 포함되어 있습니다.`를 반환한다. 재고 API는 4개 사이즈를 구매 가능으로 표시한다. 프로그램은 이 상품의 회원가를 비워 두고 "회원가 확인 실패"로 표시하며, 품절이나 공개 가격으로 바꾸지 않는다.

## 3. KREAM

### 3.1 가격 (로그인 없음)

`options/display` API는 로그인 없이 응답한다. 요청 헤더의 API 버전은 페이지 내장 설정에서 읽은 `64`, 빌드 버전은 `26.13.5`였다(코드 상수는 `52`, `25.15.7`이었고 이 값으로는 403).

KREAM 74130 (아식스 조그 100 T 블랙 2E): 사이즈 17개(W220~W290), 즉시구매가 9개, 즉시판매가 7개. W240은 해외배송 93,000원과 일반배송 108,000원 중 93,000원을 선택. W257.5 이상 8개 사이즈는 구매 입찰만 가능해 즉시구매가 없음. 같은 시각 상품 페이지의 표시 가격 93,000원과 일치.

KREAM 36 (나이키 에어포스 1 '07 로우 트리플 블랙): 사이즈 18개, 즉시구매가 17개, 즉시판매가 18개.

### 3.2 매칭

| 무신사 | KREAM | 방법 | 확인 |
|---|---|---|---|
| 1527076 | 74130 | 직접 지정 | 모델번호 1022A335-001, 블랙, 여성, mm 사이즈 일치([pricing-and-matching.md](pricing-and-matching.md) 4절) |
| 3976349 | 36 | 직접 지정 | KREAM 페이지 모델번호 `315122-001/CW2288-001`, 색상 Black/Black |
| 3976350 | 156663 (GUI 시절 미검증 매칭) | 사용 안 함 | KREAM 156663은 "나이키 x 트래비스 스캇 에어포스 1 '07 로우 캑터스 잭 유토피아 에디션"이다. 모델번호(CW2288-111)는 같지만 다른 상품이다. 미검증 매칭을 가격 수집에 쓰지 않는 이유를 보여 주는 사례다. |

자동 매칭(3976349): KREAM 검색 API는 응답했고 후보 5개(36 포함)를 받았다. 기존 검증기(`product_matcher`, OpenAI 판별 사용 설정)가 "후보 텍스트에 모델 코드가 없다"는 이유로 채택하지 않았다. 검색 카드에는 모델번호가 없기 때문이다. 결과적으로 자동 매칭은 이 상품에서 성공하지 못했고 직접 지정으로 진행했다. 첫 검색어에서는 OpenAI API가 400을 반환했다.
